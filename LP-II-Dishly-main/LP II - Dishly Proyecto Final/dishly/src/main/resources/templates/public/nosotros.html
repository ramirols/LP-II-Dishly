¿Por qué Dishly?

En el corazón de Dishly está la idea de que pedir comida no debería ser un proceso tedioso. Hemos diseñado este sistema desde cero usando Spring Boot para asegurar robustez, y una interfaz moderna para que la navegación sea intuitiva.
